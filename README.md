# MonkeyVault

A repository for my custom Userscripts.

## Installation

1. Install a Userscript manager (I recommend [Tampermonkey](https://www.tampermonkey.net/)).
2. Browse the Script List below.
3. Click the **Install** link next to the script you want.
4. Confirm the installation in your browser's extension window.
